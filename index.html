🔊 음성(TTS) 설정

질문·답변 듣기에 Gemini 음성 모델을 써요. 키는 Google AI Studio에서 받은 Gemini API 키예요. 비워두면 AI 설정의 키를 써요(AI를 Gemini로 골랐을 때).

처음 한 번, Firebase 콘솔 → Firestore → 규칙에 아래 블록을 match /sync/{code} 블록 옆에 추가하고 게시해주세요.
match /syncaudio/{id} { allow get, create, update: if true; allow list, delete: if false; }
내 기기/PC에서 음성 만들기 설정

Kokoro: 폰이든 PC든 브라우저 안에서 음성을 만들어요. 처음 한 번 약 90MB를 내려받고, 이후에는 인터넷 없이 쓸 수 있어요. 만든 음성은 이 기기에 저장돼요.

PC 서버: Kokoro-FastAPI 같은 OpenAI 호환 TTS 서버를 PC에서 켜두면 연결할 수 있어요. 같은 PC 브라우저에서만 쓸 수 있어요.
